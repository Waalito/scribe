# Scribe

Scribe es una estructura inicial para un juego web narrativo construido con Astro, TypeScript, Tailwind CSS y Three.js.

```bash
pnpm install
pnpm dev
```

## 🎯 Filosofía del proyecto

- Priorizar inmersión sobre cantidad.
- Mantener claridad y simplicidad en la arquitectura.
- Preparar la base para narrativa, audio y escenas 3D sin lógica de gameplay por ahora.
